# Secure Environment Setup

Research workflow for security-aware system and environment setup tasks.

Primary files:

- Workflow: `.archon/workflows/research/secure-environment-setup.yaml`
- Commands: `.archon/commands/research/secure-env-*.md`
- Policy corpus: `.archon/data/research/secure-environment-setup/setup-environment-policies.json`
- Docker comparison report: `reports/secure-environment-setup/docker-comparison.md`

The workflow is intentionally separated from Archon's bundled default assets. It is project-local research material for demonstrating policy-guided setup behavior.
