# GRASP Secure Coding

Research workflows and data for GRASP-style security-guided code generation.

Primary files:

- GRASP workflow: `.archon/workflows/research/grasp-secure-coding.yaml`
- Flat secure-coding workflow: `.archon/workflows/research/secure-coding.yaml`
- SCP graph: `.archon/data/research/grasp-secure-coding/scp-graph.json`
- OWASP SCP reference: `.archon/data/research/grasp-secure-coding/owasp-scp.md`
- Workflow comparison report: `reports/grasp-secure-coding/workflow-comparison.md`

The SCP reference files are data, not executable command prompts, so they live under `.archon/data/research/`.
